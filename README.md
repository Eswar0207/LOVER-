# 💖 Our Love Story — For Naa Gaaju Bomma 💖

A romantic, interactive digital love gift and memory scrapbook web application dedicated to **Naa Gaaju Bomma**.

> **"FOREVER MY GAJJU BOMMAAAA ♥ ♾️"**

---

## ✨ Features

- 🎁 **The Magic 3D Gift Box**: Interactive gift box that unlocks with romantic sound effects and chime animations.
- 🌸 **Blooming Flower Wall**: Over 300+ blooming flowers that open across the screen and part like curtains to reveal the next chapter.
- 🔐 **Passkey Security**: Passcode unlock (`7777`) with interactive keypad and vibration feedback.
- ⏳ **Love Journey Real-time Counter**: Tracks time together since October 20, 2026 down to the second and counts total heartbeats.
- 📸 **Polaroid Memory Wall**: 24 real girlfriend photos with interactive likes and fullscreen Lightbox view.
- 💌 **Wax-Sealed Love Letter**: Interactive wax seal that breaks to reveal a handwritten Telugu love letter with typewriter animation.
- 🎵 **Gaaju Bomma Song in Loop**: Features the romantic *Gaaju Bomma* song playing continuously in a loop with an ambient floating music player.
- ♾️ **Ending Keepsake**: Shimmering sign-off and infinity badge reading `FOREVER MY GAJJU BOMMAAAA ♥ ♾️`.

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Eswar0207/LOVER-.git
   ```
2. Open the folder and launch a local web server:
   ```bash
   python -m http.server 8080
   ```
3. Open `http://localhost:8080` in your web browser.
